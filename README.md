# Bridge results

Published results of our bridge tournaments: **https://strohsackj.github.io/bridge-results/**

Each tournament is one folder named `YYYY-MM-DD-name`, made by the Bridge Tournament Manager
(Dashboard → Publish results → *Download results website*). The front page lists the folders by itself, newest first.

## Adding a tournament
1. Download the results website from the app and unzip it. You get one folder, e.g. `2026-11-10-klubski-turnir`.
2. Here on GitHub: *Add file → Upload files*, drag in that **folder** (not the .zip), then *Commit changes*.
3. About a minute later it is on the front page, and the direct link is
   `https://strohsackj.github.io/bridge-results/2026-11-10-klubski-turnir/`.

To correct a tournament, upload the new folder with the same name again (the files are replaced).
To remove one, open the folder and delete its files.

## One-time setup
*Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.*
